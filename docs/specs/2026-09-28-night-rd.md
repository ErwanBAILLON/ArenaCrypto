## Recherche (données 2021-07 → 2026-09, 402 perps point-in-time, coûts d'impact à 1 M$)

### IC brute sur cinq ans (`ic5y.py`)

Corrélation de rang entre chaque colonne du panel et l'excès de rendement à 7
jours, 253 semaines. Une seule famille de features est stable **toutes les
années, même signe, t ≈ −10 à −12** : la volatilité et la loterie.

| feature | IC moyen | t | 2021 | 2025 |
|---|---|---|---|---|
| idio_vol | −0,166 | −11,6 | −0,08 | −0,27 |
| vol_garman_klass_30d | −0,168 | −10,5 | | |
| max5_daily_ret | −0,154 | −10,6 | −0,07 | −0,26 |
| funding_vol | −0,118 | −10,5 | | |
| min_daily_ret | +0,126 | +8,3 | | |
| beta_market | −0,119 | −6,6 | | |
| skew_30d | −0,080 | −7,4 | | |

Le momentum (ret_60d) est **négatif** sur cinq ans (t −3,9) : en crypto
cross-sectionnel, ce qui a monté sur deux mois fait moins bien la semaine
suivante. L'effet volatilité se renforce d'année en année, ce qui est la
signature d'un marché de plus en plus peuplé de jetons qui saignent.

Contradiction à résoudre : la même information, dans `xs_sparse` (livre
hedgé, échelle de ROI, coûts à 1 M$), donne un Sharpe médian de −0,09 sur 21
trimestres. Soit le livre détruit la prime (sorties, hedge, turnover), soit la
prime n'est pas réalisable (la jambe short de jetons illiquides paie le
funding et l'impact). `lowvol_wf.py` isole les deux : composite de rang pur,
sans échelle, quatre bras (long/short à frais plats, long/short à 1 M$, long
seul, short seul).
